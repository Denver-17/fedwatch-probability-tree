# FedWatch probability tree, 2026 (derived data)

Market-implied probabilities of every target-range outcome at the next four FOMC meetings (September 16, October 28, and December 9, 2026, and January 27, 2027), for every weekday session from August 3 to November 19, 2026, computed with my FINM 32800 HW 2 FedWatch replication, extended to CME's multi-meeting probability tree. Only the probabilities are published here, never futures prices or EFFR values. `chartbook.toml` declares the table, so that the FINM 32800 class report can depend on it.
